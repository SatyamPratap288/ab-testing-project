# Marketing Campaign Analytics & Statistical Decision Support Framework



## Business Problem

Businesses invest in multiple digital advertising platforms, but campaign performance can vary across conversions, clicks, advertising costs, and time.

Simply comparing overall campaign averages may not be sufficient to understand whether observed differences are statistically meaningful or financially sustainable.

This project develops a data-driven Marketing Campaign Analytics and Statistical Decision Support Framework to evaluate digital advertising performance using descriptive analytics, correlation analysis, hypothesis testing, regression analysis, time-based analysis, financial efficiency metrics, and Bayesian probability modeling.

The objective is to understand campaign performance, identify relationships between advertising activity and conversions, estimate expected conversions, evaluate customer acquisition costs, analyze performance trends over time, and quantify uncertainty to support data-driven marketing and budget allocation decisions.

# Solution

This project provides an end-to-end analytics framework for evaluating digital advertising campaigns.

The framework combines:

- Exploratory Data Analysis (EDA)
- Campaign performance comparison
- Conversion and click analysis
- Correlation analysis
- Statistical hypothesis testing
- Linear regression
- Time-based campaign analysis
- Cost Per Acquisition (CPA) analysis
- Cointegration analysis
- Bayesian probability modeling
- Monte Carlo simulation

# Key Analytical Components

### 1. Campaign Performance Analysis
Compare clicks, conversions, views, CTR, conversion rates, and advertising costs across Facebook and AdWords.

### 2. Statistical Analysis
Use correlation analysis and hypothesis testing to determine relationships and statistically significant differences between campaigns.

### 3. Predictive Analysis
Use Linear Regression to estimate Facebook conversions based on the number of Facebook ad clicks.

### 4. Time-Based Analysis
Analyze campaign conversions and cost efficiency across weekdays and months.

### 5. Financial Efficiency Analysis
Calculate Cost Per Acquisition (CPA) to compare the advertising cost required to generate customers.

### 6. Long-Term Relationship Analysis
Use cointegration analysis to examine whether advertising cost and conversions exhibit a long-term equilibrium relationship.

### 7. Bayesian Risk Assessment
Use Beta distributions and Monte Carlo simulation to estimate the probability that one campaign's underlying conversion rate exceeds the other's.
